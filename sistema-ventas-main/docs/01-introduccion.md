# Guia 1 - Mi propio caso de negocio
## Datos del negocio
- Nombre del negocio: Artesano 3D impresiones
- Quien lo dirige: Luis Fernando Vallejo Montaño
## Situación actual
Hoy en dia las ventas son manejadas mediante la plataforma Whatsapp de forma directa mediante contacto directo con el cliente, sin ningún tipo de registro de ningún dato. 
## Problema
Debido a que no existe ningún tipo de registro, no existen datos de ventas, ganancias, clientes, frecuencia de accesos, visitas, emails, clientes nuevos. 
## Lo que necesita
Un sitio web, un landing page donde el cliente pueda acceder tanto para realizar el registro de visita como para reconocer el producto, realizar registro de precios, ventas, visitas frecuentes para así poder reaccionar con ecommerce.
