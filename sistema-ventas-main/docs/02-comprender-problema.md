Luis

## Qué problema tienen hoy
Se acaba el producto y no se dan cuenta
Ignoran cuántas ventas se realizaron
No se entiende lo que se escribe

## Qué esperan del nuevo sistema
Que los tres involucrados puedan registrar una venta rápida
Poder ver la sección ventas, producto ingresado y egresado, inventario a tiempo. 

## Actores del Sistema
- **Don Ernesto** (directo): ver ventas totales e inventario, aunque sea desde su celular.
- **Marta y Luis** (directos) : registrar una venta rápido, sin complicarse.
- **Clientes 7 Contratistas** (indirectos): ser atendidos más rapido y con menos errores. 

## Planteamiento del Problema 
### Ferreteria San Martin
Don Ernesto, Marta y Luis tienen el problema de que se acaba el producto y no se dan cuenta; ignoran cuántas ventas realizaron; no entienden lo que escriben en la libreta, lo cual cuesta tiempo para aprender y corregir errore, dinero ya que no se realiza la venta. Una solución exitosa debería registrar ventas rápidamente, visualizar las ventas y captar el inventario a tiempo.
